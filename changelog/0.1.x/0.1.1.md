# 0.1.1 — 2026-10-19

## Added

- **Drought workflows:** current or dated severity, weekly history, state and county rankings, and county drought durations across supported national, state, county, HUC, tribal and climate-division geographies; missing observations and source provenance remain explicit.
- **Reference discovery:** paginated geography identifiers, drought categories, coverage and experimental DSCI documentation without an API key.
- **Dataframe analysis:** complete oversized results stage into bounded DuckDB tables for metadata inspection and paginated read-only SQL; disposable table removal is opt-in through `DROUGHT_DATAFRAME_DROP_ENABLED`.
- **Claude Desktop bundle:** portable inline-only results with `CANVAS_PROVIDER_TYPE=none`; npm and Docker installations include native DuckDB for staging and SQL.

## Fixed

- **Analytical capacity:** reclaim empty expired staging canvases while preserving live tables and in-flight work. ([#1](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/1))
- **Acquisition cancellation:** abort and settle sibling requests before returning a workflow failure or releasing its admission slot. ([#2](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/2))

## Dependencies

- **`@duckdb/node-api`:** added at `^1.5.6-r.1` for analytical tables and SQL.
