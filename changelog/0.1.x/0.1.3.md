# 0.1.3 — 2026-10-24

## Changed

- **`drought_list_reference`** filters climate divisions by state and HUC descendants by `parentHuc`, with climate-state mappings and source evidence in the refreshed offline bundle. ([#11](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/11))
- **Tabular output** renders reference records, query rows and describe columns as compact lossless JSON-cell tables, including clickable nested URLs; reference provenance selects complete records for the requested topic. ([#12](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/12))
- **Input ergonomics** advertise calendar-date patterns, clamp positive page limits with `effectiveLimit` and `limitNotice`, accept unique suffix-free county names after exact matches, and clarify HUC and duration recovery guidance. ([#13](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/13))
- **`drought_dataframe_query`** accepts one optional terminal semicolon and trailing comments, preserves supported DuckDB reads and literal values, and classifies forbidden statements before query wrapping. ([#13](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/13))
- **Hosted access** is documented in the README and advertised through MCP Registry remote metadata.
- **Bun** 1.4.3 → 1.4.4 in the package manager declaration and all container stages.

## Fixed

- **Latest-publication discovery** aligns both lookup endpoints to Tuesday map dates, avoiding rejection of valid covering-week observations. ([#15](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/15))
