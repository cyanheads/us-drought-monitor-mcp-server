# 0.3.0 — 2026-11-21

## Added

- **Producer paging** gives `drought_get_timeseries` and `drought_compare_areas` exact opt-in row counts. Continue from the full staged table or, with analytics disabled, use the cursor to read the same snapshot. ([#25](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/25))
- **Analytical admission** queues producers and SQL reads independently before execution, with separate two-slot pools, eight waiters each, and a 15-second wait. ([#27](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/27))

## Changed

- **Rendered metadata** uses lossless JSON-cell tables for record collections and preserves clickable provenance links. ([#26](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/26))
- **`drought_dataframe_query`** now rejects 35 DuckDB metadata-view names as column aliases (quoted or unquoted), selected column names, or CTE names. Use another identifier, such as `local_count`. String literals are unchanged.
- **Release tooling** uses the updated framework checks and bundle pruning rules, preserving runtime entries with names that resemble agent documentation.

## Fixed

- **County lookup** recognizes independent-city short names, reports the city's FIPS when a shared name selects its county, and handles `St` and `Ste` in county names and filters. ([#23](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/23))
- **Time-series acquisition** batches bundled counties, same-level HUCs, and climate divisions in bounded map-week windows within existing quotas, resolves climate DSCI by state and division number, and builds missing-date runs in one pass per area and metric component. ([#24](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/24))
