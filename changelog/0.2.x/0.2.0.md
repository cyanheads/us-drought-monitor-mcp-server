# 0.2.0 — 2026-10-26

## Added

- **River Forecast Centers:** discover 13 official RFCs and retrieve snapshots, weekly area statistics and DSCI by code or exact name; population remains unsupported ([#20](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/20)).
- **`us-drought-monitor-guide`:** publish an agent guide for geography resolution, interpretation and complete analytical retrieval, discoverable through MCP skill resources and the `skill://{+path}` template.
- **Population provenance:** carry the official estimation methodology and precision caveat through snapshots, population series and retained describe/query results without rounding source values ([#19](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/19)).
- **`DROUGHT_CLAMP_LIMITS`:** default-on clamping emits request logs and the `drought.limit_clamps` counter; `false` advertises and enforces page maxima ([#21](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/21)).

## Changed

- **Explicit pages:** reference, duration, SQL and retained metadata return the effective requested count, fewer only at exhaustion; wide values remain complete. Reference, duration and SQL defaults are 25; comparison previews and metadata remain 20 ([#21](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/21)).
- **SQL migration:** unqualified `current_schema` references now fail with `sql_read_only` / `denied_function`, including references to a column of that name. Qualify the column with its table (`c.current_schema`).
- **Inline producers:** with analytics disabled and no explicit token, return complete results within acquisition limits. Producer staging and metadata prefixes retain full data, including oversized singleton/fixed metadata and zero-row tables ([#21](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/21)).
- **Development tooling:** sync framework skills, packaging checks and audit classification; add Agent Plugins root manifests and use a one-day minimum dependency release age.

## Fixed

- **Pagination notices:** exhausted SQL offsets no longer claim the whole query has no matches; clamped comparisons mention staged continuation only when rows remain there ([#17](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/17)).
- **Metadata limits:** clamp positive `metadata_limit` values above 100 with dual-surface disclosure and exact retained continuation ([#18](https://github.com/cyanheads/us-drought-monitor-mcp-server/issues/18)).
- **Bundle pruning:** preserve SDK runtime skill modules while stripping dependency agent documentation, native bindings and build-only artifacts; guard long dependency paths with regression coverage.
